# 🎮 HVH ARENA // NO INTEGRITY (CS:GO HvH Simulator)

> **Старые добрые HvH сервера CS:GO прямо в браузере! "Читы" — это не нарушение правил, а соревновательная основа геймплея.**

Игра работает полностью в 3D на **Three.js** и поддерживает сетевую игру с друзьями через бесплатный **P2P WebRTC (PeerJS)** прямо с хостинга **GitHub Pages**!

---

## 🌟 Новые возможности и обновления

### 🖥️ 1. Главное меню (CS2 / HvH Hub)
При входе в игру вы попадаете в полноценное главное меню с кинематографичной панорамой карты `de_mirage`:
* **🤖 Игра с ботами (Practice)**:
  * Настройка количества ботов (от 0 до 6).
  * Выбор конфига ботов: *Scout Tap God*, *Skeet 2018 HvH*, *Neverlose Aggro*.
* **🌐 Сетевая игра (Online WebRTC)**:
  * **Room Browser (Список комнат)**: подключайтесь к созданным серверам в один клик.
  * **Создание своей комнаты**: имя комнаты, приватность, пароли и лимит игроков (1v1, 2v2, 8 игроков).
  * **Прямое подключение**: вход по ID комнаты и паролю, а также моментальный вход по ссылке (`?room=XYZ&pwd=...`).
* **👤 Профиль игрока**:
  * Смена никнейма в реальном времени.
  * Выбор аватарки и статус "Global Elite // Sub: Lifetime".

### 🎨 2. Skinchanger и Ножи (Скинчейнджер)
* **Стандартное стартовое оружие**: **SSG 08 (Scout)** с легендарным 100% Jump-scouting в прыжке!
* **Коллекция скинов**:
  * **SSG 08 (Scout)**: *Dragonfire* (Огненный дракон), *Default Tactical*.
  * **SCAR-20 (Auto-Sniper)**: *Bloodsport* (Красно-белый спорткар), *Default*.
  * **AWP**: *Dragon Lore* (Золотой дракон), *Asiimov* (Оранжевый сай-фай), *Fade 100%* (Градиент).
  * **Desert Eagle**: *Printstream* (Перламутр с XX голографией), *Default Steel*.
  * **★ Knives (Ножи)**:
    * **Karambit Doppler (Ruby)** — кровавый кристальный рубин.
    * **Karambit Doppler (Sapphire)** — сияющий синий сапфир.
    * **Karambit Fade** — радужный градиент.
* **Анимация осмотра (Inspect)**: нажмите **`F`**, чтобы покрутить Керамбит или осмотреть оружие в руках!

### 💎 3. Мульти-Тематическое Чит-Меню (Стили Читов)
Переключайте оформление чита прямо на ходу в шапке меню:
* **Skeet / Gamesense**: темный антрацит и легендарный кислотно-салатовый `#a4d037`.
* **Neverlose.cc**: глубокий синий космос и неоновый циан `#00e5ff`.
* **Nixware.cc**: фиолетовый акцент `#b366ff` и компактные элементы.
* **Onetap v3**: классический оранжевый `#ff9900` дизайн.

### 🏜️ 4. Карта `de_mirage (A Site)`
Точная геометрия плента А Миража:
* **Palace & Balcony (Ковры)**: деревянный балкон с простреливаемой дверью для Auto-Wall!
* **Tetris**: каменные блоки возле рампы.
* **Stairs & Connector**: подъем по ступенькам и проходы в коннектор.
* **Triple Box & Firebox**: классические ящики для wallbang-дуэлей.
* **Ticket Booth (Дефолт)**: позиция снайпера у КТ.

## 🕹️ Управление в игре

| Клавиша | Действие |
|---|---|
| **W, A, S, D** | Передвижение |
| **ПРОБЕЛ (зажать)** | Авто-Баннихоп (Auto-Bhop с набором скорости) |
| **Shift / Ctrl** | Шаг / Приседание |
| **INSERT / DEL / M** | Открыть / Закрыть Чит-Меню |
| **1, 2, 3, 4, 5** | 1: SSG 08 (Scout), 2: SCAR-20, 3: Нож/Керамбит, 4: Deagle, 5: AWP |
| **F** | Осмотр оружия (Inspect Animation) |
| **ЛКМ** | Выстрел (или Auto-Fire в Ragebot) |
| **ПКМ / E** | Оптический прицел снайперки |
| **R** | Перезарядка |
| **🏠 MAIN MENU** | Выход в главное меню из матча |
