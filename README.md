# 🎮 HVH ARENA: NO INTEGRITY (CS:GO HvH Simulator)

> **Геймплей старых HvH (Hack vs Hack) серверов CS:GO, где "читы" — это не нарушение правил, а главная соревновательная механика!**

Игра работает полностью в браузере в 3D на **Three.js** и поддерживает сетевую игру с друзьями через **бесплатный P2P WebRTC (PeerJS)** прямо с хостинга **GitHub Pages** (без необходимости покупать серверы или настраивать бэкенд).

---

## 🔥 Ключевые Механики HvH

### 🎯 1. Ragebot (Аимбот)
- **Silent Aim**: Прицел игрока не дёргается на экране — пули летят в цель по баллистической траектории чита.
- **Auto-Fire**: Мгновенный выстрел в тот же тик, когда шанс попадания и урон удовлетворяют настройкам.
- **Auto-Wall (Wallbang)**: Просчёт пробития деревянных панелей и углов с расчётом остаточного урона.
- **Auto-Stop**: Мгновенное гашение скорости игрока в момент выстрела для максимальной точности.
- **Auto-Scope**: Автоматический зум снайперских винтовок перед выстрелом.
- **Hit Chance & Min Damage**: Ползунки вероятности попадания (0–100%) и порога минимального урона.
- **Double Tap (DT)**: Мгновенный сдвоенный выстрел из скорострелки (SCAR-20) или Дигла.
- **Backtrack (Lag Compensation)**: Откат тиков противника во времени до 200 мс (16 тиков) — стрельба по призракам, оставшимся за углом!
- **Hitbox Multipoint**: Выбор зон поражения (Голова, Грудь, Живот, Таз, Руки, Ноги).

### 🔄 2. Anti-Aim (Спинбот и Десинк)
- **Pitch (Наклон головы)**:
  - `Emotion / Down (-89°)`: Голова прячется в пол/грудь, делая хитбокс головы практически неуязвимым сверху.
  - `Zero (0°)`, `Up (89°)`, `Jitter`.
- **Yaw (Вращение тела)**:
  - `Backward (180°)`: Персонаж повернут спиной к противнику.
  - `Spinbot (360°)`: Быстрое вращение вокруг оси с настройкой скорости.
  - `Jitter`: Хаотичные рывки из стороны в сторону.
- **Fake Desync (Фейк-угол)**:
  - Создание двух моделей: **Real Angle** (настоящий урон) и **Fake Angle** (угол-призрак с отклонением до 58°).
  - Настоящий хитбокс смещён, вражеский аимбот стреляет по фейку и мажет!
- **LBY Flick (Lower Body Yaw)**:
  - Периодический рывок угла тела каждые 1.1 секунды, ломающий брутфорс-резорверы.
- **Fake Lag (Choke Packets)**:
  - Удержание пакетов от 1 до 14 тиков. Персонаж визуально телепортируется, сбивая интерполяцию.

### 🧠 3. HvH Resolver (Резорвер)
- Алгоритм разгадывания фейк-углов противника:
  - **Moving LBY**: Определение реального угла по направлению движения при скорости > 1.1 u/s.
  - **Brute-Force**: Пошаговый перебор сторон (+58°, -58°, 0°, half-delta). При промахе резорвер инвертирует угол.
  - **Hit & Miss Logs**:
    `[gamesense] Hit enemy in head for 100 dmg [bt: 12t, hc: 84%, res: adaptive_right]`
    `[gamesense] Missed shot due to resolver (res: brute_step_0)`

### 👁️ 4. Visuals (Визуалы & ESP)
- **2D Box ESP**: Рамки вокруг игроков с обводкой.
- **Health Bar**: Динамическая шкала здоровья (зеленый -> желтый -> красный) с цифрами ХП.
- **Name & Weapon ESP**: Отображение никнейма и активного оружия.
- **Skeleton ESP**: Линии скелета сквозь стены.
- **Off-screen Indicators**: Красные стрелки по краям экрана, указывающие на противников со спины.
- **Bullet Tracers**: Неоновые лучи трассеров (голубые для игрока, красные для врагов).
- **Hitmarkers & Hitsounds**: Классический звук кристального колокольчика (Skeet / Gamesense bell ding) при попадании и хедшоте.
- **Thirdperson Mode**: Вид от 3-го лица с отображением **Ghost Desync Model** (призрак фейк-угла).

### ⚡ 5. Оружие
- **SCAR-20**: Скорострелка, идеальный прострел стен, смертельный дабл-тап.
- **SSG-08 (Scout)**: 100% точность прыжка (Jump-scouting) и ваншот в голову.
- **AWP**: Тяжелый калибр с ваншотом в тело.
- **Desert Eagle**: Карманная пушка с ваншотом в голову.
- **Dual Berettas**: Быстрый спам при беге.

## 🚀 Как выложить на GitHub и играть с друзьями

Игра работает **без бэкенда** — сетевой код построен на **WebRTC (PeerJS)**. Это значит, что бесплатный хостинг **GitHub Pages** идеально подходит!

### Шаг 1: Создайте репозиторий на GitHub
1. Перейдите на [github.com/new](https://github.com/new).
2. Назовите репозиторий (например, `hvh-arena`).
3. Сделайте его **Public** (публичным).
4. Нажмите **Create repository**.

### Шаг 2: Загрузите файлы игры
В терминале вашей папки проекта выполните:
```bash
git init
git add .
git commit -m "Initial commit: CS:GO HvH Simulator"
git branch -M main
git remote add origin https://github.com/ВАШ_НИКНЕЙМ/hvh-arena.git
git push -u origin main
```
*(Или просто перетащите файлы через кнопку "Upload files" в веб-интерфейсе GitHub).*

### Шаг 3: Включите GitHub Pages
1. Откройте ваш репозиторий на GitHub.
2. Перейдите в **Settings** (Настройки) -> слева выберите раздел **Pages**.
3. В выпадающем меню **Source** выберите:
   - Либо **Deploy from a branch** -> Branch: `main`, папка: `/ (root)` -> Нажмите **Save**.
   - Либо **GitHub Actions** (в проекте уже лежит настроенный `.github/workflows/deploy.yml`).
4. Через 1–2 минуты обновите страницу — GitHub выдаст ссылку вида:
   `https://ВАШ_НИКНЕЙМ.github.io/hvh-arena/`

### Шаг 4: Как играть с друзьями
1. Откройте вашу ссылку в браузере.
2. Нажмите клавишу **[INSERT]** (или кнопку `⚙️ HVH MENU` внизу экрана).
3. Перейдите во вкладку **🌐 Multiplayer**.
4. Нажмите **+ CREATE MULTIPLAYER LOBBY**.
5. Скопируйте появившуюся ссылку приглашения (**Shareable Invite Link**) и отправьте другу.
6. Друг переходит по ссылке и **автоматически подключается к вашей сессии**!
7. Вы играете в одной комнате в реальном времени, тестируя анти-аимы, дабл-тапы и резорверы друг против друга!

## 🕹️ Управление в игре

| Клавиша | Действие |
|---|---|
| **W, A, S, D** | Передвижение |
| **ПРОБЕЛ (зажать)** | Авто-Баннихоп (Auto-Bhop) |
| **Shift / Ctrl** | Шаг / Приседание |
| **INSERT / DEL / M** | Открыть/Закрыть Меню Чита |
| **Левый клик** | Стрельба (или Auto-Fire в Ragebot) |
| **Правый клик / E** | Оптический прицел снайперки |
| **1, 2, 3, 4, 5** | Выбор оружия (SCAR-20, Scout, AWP, Deagle, Duals) |
| **R** | Перезарядка |

## 🤖 Одиночный режим с ботами
Если друзей нет онлайн, прямо во вкладке **Multiplayer** можно настроить количество **HvH Ботов** (ползунок от 0 до 4). Боты используют полноценный анти-аим, спинбот, десинк, автостоп, скаутинг и резорвер.
